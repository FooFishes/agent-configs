# ux

一句话立场：所有交互都要有克制而精致的动效，拒绝生硬跳变；交互范式参照 macOS；自由布局要加约束；次要信息默认折叠。

## 条目

### 所有交互都加优雅、克制的动画，生硬的切换不可接受

为什么："为该项目所有交互加上优雅,精致,合适的动画."；"为什么不加一些动画和动效呢? 现在是很生硬的界面交互呢"（同一天两次）；"对系统加一下优雅的动画, 确保页面流畅过渡, 视觉华丽"。

例外：暂无。

来源：2026-09 月 training-sys（具体日期未记）；2026-10-21、10-22 Nova；2026-10-29 eat_what_app。

### 动效要丝滑、带影子、有阻力感，对缓动曲线有具体要求

为什么："拖拽的动画可以不那样硬, 带着影子和丝滑的动画吧, 现在这个拖宅太硬显得页面变化不顺畅."；"拖动调整大小可以搞一个先慢后快的曲线, 类似有一点阻力的手感."；"连接线可以丝滑一点, 加一个流畅的动画"。

例外：暂无。

来源：2026-10-21、10-22 Nova。

### 特效要和真实物理效果对比着调，要克制且逼真，不接受"看起来像"

为什么："不够自然, 和真实的卷边效果并不一样. 你可以让页面真实的卷起来看看效果, 让两个进行对比"；"效果有点太夸张了吧"；"液态玻璃和实际的样式不太一样"。

例外：暂无。

来源：2026-11-03 至 11-06 eat_what_app。

### 交互范式参照 macOS：叠放、点一下展开、挥之即走的预览、键盘驱动

为什么："画布应当把相同的网页截取的内容归并到一起, 类似 macOS 的文件叠放或者文件夹之类."；"对于叠放, 我希望做成 macOS 的那种, 点一下可以展开"；"是一种挥之即走的类型, 类似 macOS 的 Preview."；自用工具"我希望我可以用键盘选中, 然后按 Space 去 Preview up 主的主页, 类似 macOS"，"加一个快捷键, 左右切换上一个下一个, 上下决定去留"。

例外：暂无。

来源：2026-10-06 AIC；2026-10-21 Nova；2026-10-07 至 11-03 scratch 工具页。

### 自由布局要加约束：网格吸附、自动排布、默认排好但允许手动

为什么："现在的画布是完全自由的, 可以有任意的尺寸大小. 但是这样存在问题: 我们并不好组织和排布. 下面我们需要加上小的网格 (点), 拖拽时自动吸附在格子上 ... 卡片应当有一个最小的高度, 防止文本过少导致比例失调 ... 默认是矩形的排布而不是长条 ... 组内卡片自动补位"；"自由拖动吧, 不过不过, 在默认情况下是自动排列好的."；"没必要顶部完全对齐, 错落的拼接就好"。

例外：暂无。

来源：2026-10-06 AIC；2026-10-21 Nova。
