# ux

一句话立场：所有交互都要有克制而精致的动效，拒绝生硬跳变。交互范式参照 macOS，自由布局要加约束，次要信息默认折叠。

## 条目

### 所有交互都加优雅、克制的动效，生硬切换不可接受

为什么：三个项目都在第一轮就要求加动效，"为什么不加一些动画和动效呢"。动效要丝滑、带阴影、有阻力感，拖拽调整尺寸用先慢后快的曲线。

例外：暂无。

来源：training-sys、Nova、eat_what_app，2026-09 至 10。

### 特效要和真实物理效果对比着调，克制且逼真，不接受"看起来像"

为什么：卷边"和真实的卷边效果并不一样"，要"让页面真实的卷起来对比"；液态玻璃也要对照实际样式。夸张的效果会被打回。

例外：暂无。

来源：eat_what_app，2026-11。

### 交互范式参照 macOS：叠放、点一下展开、挥之即走的预览、键盘驱动

为什么：macOS 是用户心里的交互基准，描述需求时直接拿它举例：文件叠放、Preview 那种挥之即走、空格预览、方向键取舍。

例外：暂无。

来源：AIC、Nova、scratch 工具页，2026-10 至 11。

### 自由布局要加约束：网格吸附、默认自动排好、允许手动调整、不重叠、矩形优于长条

为什么：完全自由的画布"并不好组织和排布"。默认排好但允许手动，矩形排布比长条能显示更多内容。拖拽要有明确的拖拽态和过程动画，并且能回溯到来源。

例外：暂无。

来源：AIC、Nova，2026-10。

### 次要信息默认折叠，hover 展开，字号小一号

为什么：平铺的引文编号抢视线，相关性低的内容默认收起。

例外：暂无。

来源：AIC、Nova，2026-10。

### 状态要一致、细节要到位：改完状态不让用户重新登录，加载态不闪默认色，弹窗避让手势条，点击区域够大

为什么：移动端的这些细节决定品质感。"用户名设好了为什么要重新登录"这类问题是不可接受的。

例外：暂无。

来源：isdu-app、eat_what_app，2026-09 至 11。
