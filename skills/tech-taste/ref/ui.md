# ui

一句话立场：简约、克制、信息密度高；去装饰，主色偏稳，字重字号克制，细节用设计师的眼睛看，宽屏也要好看。

## 条目

### 去装饰：不加图标背景块、不加左侧色条、不加无意义的图标、不做发光效果

为什么："通知中心的通知, 左侧不要加重色竖条, 不要加上 Icon."；看到统计卡片图标后的圆角背景说"把这个删掉"；"曲线连到卡片的边框就好, 否则像是出头了一样 然后不做发光效果."

例外：暂无。

来源：2026-09-28 training-sys（Codex）；2026-10-21 Nova。

为什么：首字母圆圈"不太美观"，因为"产品没有头像功能"，要求删掉并换成姓名、身份标签和辅助信息的两行结构。

例外：暂无。

来源：2026-09-28 training-sys（Codex）。
