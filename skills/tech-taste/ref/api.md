# api

一句话立场：响应统一包成 code、message、data，成功码 0，业务码全局单一空间；OpenAPI 进仓库当契约，客户端严格照后端最新实现，未定的部分留空不编。

## 条目

### 响应包装器就是一个泛型的 code、message、data；成功码为 0；业务码全局单一编号空间，不按模块拆

为什么："code 是业务码...成功可以改成 0"；"我们没有拆分模块, 就使用全局的Code就可以, 业务码上进行划分"；"Result 就作为一个泛型 code message data 包装器即可."。前端随后统一改为 code 等于 0 判成功。不为不存在的边界预留结构。

来源：2026-09-27 training-sys。

### OpenAPI 文档放进仓库作为前后端契约，用脚本同步，定期对照代码找偏差
